# AI Context

Yonas Workout Tracker is a simple, mobile-first strength-training PWA. It stores workout data locally and is designed to remain usable offline.

## Before Modifying the Project

1. Read the relevant files in `/docs`.
2. Inspect the relevant existing implementation.
3. Preserve existing behavior unless explicitly instructed otherwise.
4. Modify only files relevant to the requested task.
5. Avoid unrelated cleanup or refactoring.
6. Prefer small incremental changes.
7. Explain significant architectural changes.
8. Do not introduce breaking changes without explicit approval.

## Project Philosophy

- Simple
- Maintainable
- Mobile-first
- Offline-capable
- Incremental development
- Avoid unnecessary complexity

The intended architecture separates UI, business logic, and storage, but the current JavaScript has not yet fully implemented those boundaries. Treat that separation as an incremental direction rather than an existing fact.
