# Project Overview

## Project

**Yonas Workout Tracker** is a mobile-first strength-training tracker designed for simple, fast workout logging. It is a Progressive Web App (PWA) with an offline-first approach and is currently deployed through GitHub Pages.

The current technology stack is:

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage
- Service Worker and PWA web manifest

Development takes place in Visual Studio Code. GitHub is used for source control and GitHub Pages deployment.

## Development Workflow

### Human developer

- Is the final decision maker.
- Tests and approves changes.

### ChatGPT

- Supports architecture work.
- Helps design products and features.
- Provides technical decision support.
- Reviews code.
- Creates implementation instructions for Codex.

### Codex

- Reads the existing codebase before making changes.
- Implements approved changes.
- Refactors code when requested.
- Creates or updates project files.
- Runs relevant checks where possible.
