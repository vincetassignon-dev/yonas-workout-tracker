# Coding Guidelines

- Do not rewrite working code unnecessarily.
- Keep functions focused on a clear responsibility.
- Prefer readable code over clever code.
- Minimize duplication.
- Preserve backward compatibility where practical.
- Comment non-obvious logic and explain why it is needed.
- Prefer small, reviewable changes.
- Test existing functionality after modifications.
- Avoid introducing dependencies unless they provide clear value.
- Do not introduce a framework without an explicit architectural decision.
