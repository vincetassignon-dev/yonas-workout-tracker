# Roadmap

This roadmap describes direction, not completed functionality. Items remain planned or possible until they are implemented and verified in the application.

## Alpha 0.3

- Refactor the project structure.
- Improve separation between UI, business logic, and storage.
- Preserve all existing functionality while refactoring.
- Improve maintainability.
- Continue improving PWA update and cache behavior.

Some Alpha 0.3 structure and cache work is visible in the repository, but the architectural separation remains an ongoing goal.

## Potential Future Work

- A broader exercise library.
- Reusable workout templates.
- Expanded statistics.
- Expanded personal-record features.
- Improved progress graphs.

## Longer-Term Possibilities

- User profiles.
- Optional cloud synchronization.
- Advanced analytics.

These future and longer-term items are possible directions, not commitments or claims about current implementation.
